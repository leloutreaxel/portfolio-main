Certification Montage d'un PC

Dans cette formation, j’ai appris à assembler un ordinateur en choisissant les composants adaptés, en les installant correctement et en configurant le système pour assurer son bon fonctionnement.

Formation Open ClassRooms 🔗 Lien internet : : https://openclassrooms.com/fr/courses/7210326-montez-un-pc

Mes objectifs

Comprendre les composants essentiels d’un PC
Choisir les bonnes pièces en fonction des besoins
Assembler un ordinateur étape par étape
Installer et configurer le BIOS/UEFI
Installer un système d’exploitation (Windows/Linux)
Tester et optimiser le PC après l’assemblage

Pourquoi cette formation ?

Acquérir des compétences techniques pour mon BTS SIO
Appliquer ces connaissances lors de mon stage en entreprise
Développer des compétences utiles pour mon avenir professionnel dans l’informatique

Les outils que j'ai utilisé

🛠 Tournevis cruciforme : Pour fixer les composants
⚡ Bracelet antistatique : Pour éviter les décharges électrostatiques
🖥️ BIOS/UEFI : Pour configurer le matériel avant l’installation du système
💿 Clé USB bootable : Pour installer Windows ou Linux

Quelques notions à travers des images

1. Choix des composants

Chaque élément doit être compatible avec les autres pour garantir un bon fonctionnement. Exemple de configuration pour un PC gaming :
●Processeur : AMD Ryzen 7
●Carte mère : B550-R GAMING
●Mémoire RAM : 16 Go DDR4
●Carte graphique : NVIDIA RTX 4060
●Stockage : SSD NVMe 1 To
●Alimentation : 750W certifiée 80+
●Refroidissement : Watercooling Corsair Nautilus 360 RS ARGB

2. Montage du PC

L’assemblage suit un ordre précis : 1️⃣ Installer le processeur sur la carte mère 2️⃣ Ajouter la RAM et le refroidissement 3️⃣ Placer la carte mère dans le boîtier 4️⃣ Installer l’alimentation et brancher les câbles 5️⃣ Ajouter la carte graphique et le stockage 6️⃣ Vérifier les branchements et allumer le PC

3. Configuration du BIOS et installation du système

Avant d’installer l’OS, il faut configurer le BIOS pour reconnaître les composants. Exemple de commandes :

Accéder au BIOS : Appuyer sur DEL ou F2 au démarrage
Activer le mode AHCI pour le SSD
Booter sur la clé USB avec l’OS
